# Capturas reales de la tienda virtual (diapositiva 17)

Coloca aquí las capturas de pantalla de Ksmart360 para que la diapositiva
"Tu tienda en internet" muestre el sistema real:

- **`catalogo.png`** → la captura del **catálogo/tienda** (ej. la vitrina de
  Calzado EYA con los productos). Es la imagen principal, dentro del navegador.
- **`pedido.png`** → la captura del **pedido recibido/enviado** (ej. la pantalla
  "¡Pedido enviado! #7" o el panel de Pedidos). Aparece como tarjeta flotante.

Formato recomendado: PNG, ancho ~1000–1400 px.

Si un archivo no existe, la diapositiva muestra automáticamente un respaldo
(mock) para que nunca se vea rota. En cuanto agregues los archivos y hagas
`git add` + commit + push, la presentación usará las imágenes reales.
